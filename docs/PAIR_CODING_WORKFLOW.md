# 페어코딩 수업 방식

이 수업은 완성된 코드를 전달받는 방식이 아니라, 하나의 제품을 함께 만들어가는 방식으로 진행합니다. 수업 시간에는 학생과 튜터가 번갈아 코드를 작성하고, 수업 사이에는 학생이 남은 작업을 진행해 PR(Pull Request)을 보냅니다.

## 수업 진행 방식

### 0. 지난 PR 피드백과 리팩터링

지난 수업 이후 학생이 보낸 PR을 함께 실행하고 테스트합니다. 학생은 먼저 아래 내용을 설명합니다.

1. 무엇을 만들려고 했는가
2. AI에게 무엇을 요청했는가
3. 어떤 코드를 이해하지 못했는가
4. 무엇을 직접 실행하고 테스트했는가
5. 현재 가장 불안한 부분은 무엇인가

설명을 바탕으로 잘된 점과 개선할 점을 확인하고, 필요하면 함께 리팩터링합니다. PR이 완성되지 않았거나 오류가 남아 있어도 괜찮습니다. 어디까지 시도했고 무엇에서 막혔는지 확인한 뒤 그 상태부터 이어서 작업합니다.

### 1. 티켓 합의

페어코딩을 시작하기 전에 이번에 작업할 티켓을 함께 확인하고 다음 내용에 합의합니다.

- 이번에 구현할 범위
- 티켓의 완료 조건
- 직접 확인할 정상 상황과 실패 상황

구현 중에 기존 티켓의 요구사항이 모호하거나 실제 상황과 맞지 않는 부분을 발견하면, 임의로 구현하지 않고 변경 방향을 함께 토론합니다. 합의한 내용을 티켓에 반영한 뒤 변경된 기준으로 작업을 계속합니다.

### 2. 페어코딩과 피드백

한 사람이 30분 동안 드라이버로 작업하되, 이 시간에도 드라이버와 네비게이터는 계속 대화하며 함께 구현합니다. 이어지는 10분 동안에는 방금 작업한 방식, 이해하지 못한 부분과 개선점을 정리해 피드백합니다. 피드백이 끝나면 역할을 바꾸고 같은 과정을 반복합니다.

드라이버는 키보드와 AI 도구를 직접 조작하고, 네비게이터는 목표와 다음 단계를 함께 정하며 작성된 코드와 실행 결과를 검토합니다. 어느 역할이든 판단은 대화를 통해 함께 내립니다.

#### 학생이 드라이버일 때

학생은 키보드와 AI 도구를 직접 조작해 코드를 작성하고 실행·테스트합니다. 튜터는 네비게이터로서 다음에 확인할 작은 단계를 제안하고, AI가 제안한 코드와 오류 메시지를 함께 검토하며, 학생이 판단할 수 있도록 질문과 필요한 설명을 제공합니다.

#### 튜터가 드라이버일 때

튜터는 키보드와 AI 도구를 직접 조작합니다. 학생은 네비게이터로서 만들려는 동작, 예상 결과와 다음에 확인할 내용을 말하고, 작성된 코드와 실행 결과를 검토합니다. 튜터는 필요한 질문으로 방향을 함께 정하고, 무엇을 확인하며 왜 그렇게 판단하는지 생각 과정을 소리 내어 설명합니다.

#### 역할을 교대할 때

튜터는 모든 작업을 완성한 뒤 넘기지 않습니다. 다음 판단이나 작은 문제를 남겨 학생이 직접 이어서 해결할 수 있도록 합니다.

### 3. 수업 이후 PR (과제)

수업에서 남은 분량이나 다음 티켓은 학생이 가능한 시간에 자유롭게 이어서 작업합니다. AI를 사용해도 되지만, AI가 작성한 코드도 학생이 직접 실행하고 테스트합니다.

리뷰가 필요하면 완료 여부와 관계없이 PR을 보낼 수 있습니다. 다음 수업에서는 해당 PR에 대한 피드백부터 다시 시작합니다.

> 지난 PR 피드백 → 티켓 합의 → 30분 페어코딩 → 10분 피드백 → 역할 교대 → 남은 작업 진행과 PR

## 4. UI 피드백(모달 & 토스트) 동기화 규칙

새로운 티켓을 구현하거나 수정하는 과정에서 **모달 대화상자**나 **토스트 알림**이 추가·변경되는 경우, 다음 규칙을 준수합니다:

1. **디자인 및 문체 규격 준수**:
   - 확인 질문형 모달은 Yes/No를 금지하고 `chzzk_downloader.gui.dialogs.ask_confirm_dialog`를 사용하여 **[확인] / [취소]** 명시 및 **'확인' 버튼 기본 하이라이트**를 적용합니다.
   - 문체는 질문형 `~하시겠습니까?`, 안내형 `~합니다.` / `~되었습니다.`를 준수합니다.
2. **문서 및 쇼케이스 주기적 갱신**:
   - [`docs/UI_FEEDBACK_CATALOG.md`](file:///c:/Users/이홍원/Desktop/code_training/chzzk_downloader/docs/UI_FEEDBACK_CATALOG.md)의 카탈로그 표에 신규/수정 항목을 즉시 등록합니다.
   - [`src/chzzk_downloader/gui/feedback_showcase.py`](file:///c:/Users/이홍원/Desktop/code_training/chzzk_downloader/src/chzzk_downloader/gui/feedback_showcase.py)에 데모 버튼을 추가하여 개발자가 눈으로 직접 확인할 수 있도록 합니다.
3. **자동화 테스트 검증**:
   - `uv run pytest tests/test_ui_feedback_catalog.py`를 실행하여 문체와 버튼 하이라이트 규격이 통과하는지 검증합니다.
